[![TypeScript](https://img.shields.io/badge/TypeScript-5-blue.svg)](https://www.typescriptlang.org/)
[![TailwindCSS](https://img.shields.io/badge/TailwindCSS-3-38bdf8.svg)](https://tailwindcss.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

Modern, responsive dashboard for visualizing trading strategy performance built with React, TypeScript, and Recharts.

## Features

- **Real-time Charts**: Interactive equity curves and performance charts
- **Strategy Comparison**: Side-by-side strategy analysis
- **Performance Metrics**: Sharpe ratio, drawdown, win rate
- **Trade History**: Detailed trade log with filtering
- **Responsive Design**: Mobile-first with TailwindCSS
- **Dark Mode**: Built-in theme switching

## Tech Stack

- React 18 with TypeScript
- Recharts for data visualization
- TailwindCSS for styling
- Vite for fast development

## Installation

```bash
npm install
npm run dev
```

## Components

- `EquityCurve`: Line chart showing portfolio value over time
- `PerformanceMetrics`: Key statistics cards
- `TradeTable`: Sortable, filterable trade history
- `StrategyComparison`: Multi-strategy performance comparison
