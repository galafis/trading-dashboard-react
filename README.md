## English

### 🎯 Overview

**Trading Dashboard React** — Real-time trading dashboard built with React and TypeScript. Displays live market data, portfolio performance, trade history, and interactive charts with WebSocket updates.

Total source lines: **3,105** across **34** files in **5** languages.

### ✨ Key Features

- **Production-Ready Architecture**: Modular, well-documented, and following best practices
- **Comprehensive Implementation**: Complete solution with all core functionality
- **Clean Code**: Type-safe, well-tested, and maintainable codebase
- **Easy Deployment**: Docker support for quick setup and deployment

### 🚀 Quick Start

#### Prerequisites
- Node.js 20+ and npm


#### Installation

1. **Clone the repository**
```bash
git clone https://github.com/galafis/trading-dashboard-react.git
cd trading-dashboard-react
```

2. **Install dependencies**
```bash
npm install
```

#### Running

```bash
npm run dev
```


### 🧪 Testing

```bash
npm test
```
